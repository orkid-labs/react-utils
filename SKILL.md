# react-utils

react-utils collects the small helpers Orkid's frontends share: number/address formatting, className merging, and display utilities used across the swap widget and dashboards.

## When to use

You want the formatting/class-merge helpers used inside @orkid-labs/widget without copying code.

## Install

```
npm install @orkid-labs/react-utils
```
